## 🗄️ Database

**Database Name:** `sportmart_db`

**SQL File:** `sportmart_db.sql`

## 🚀 Installation & Setup

1. **Clone or Download** this repository into your `C:\xampp\htdocs\` directory.

2. **Start XAMPP** Control Panel and ensure **Apache** and **MySQL** are running.

3. **Import the Database**:
   - Open phpMyAdmin in your browser ([http://localhost/phpmyadmin/](http://localhost/phpmyadmin/)).
   - Create a new database named `sportmart_db`.
   - Go to the **Import** tab, upload your `sportmart_db.sql` file, and click **Go**.

4. **Access the Project**:
   - Open your browser and navigate to: [http://localhost/PHP_Group01_Project/](http://localhost/PHP_Group01_Project/)
